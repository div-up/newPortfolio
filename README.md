
# My Portfolio

A personal portfolio website showcasing my skills, work experience, projects, and professional journey as a developer.

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- React Icons
- Lucide React
- EmailJS

## Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
cd newportfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |

## Production Build

```bash
npm run build
```

The production-ready files will be generated in the `dist/` directory.
